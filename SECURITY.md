# Security Policy

## Reporting a vulnerability

If you believe you have found a security or privacy issue in a Rascend Technologies app or website, please email **<support.rascend@gmail.com>** with the subject line "Security report".

Please include:
- which app or site is affected,
- steps to reproduce the issue,
- what you think the impact is.

Please do not publicly disclose the issue until we have had a reasonable chance to fix it. We aim to acknowledge reports within 5 working days.

Do not access other people's data, run denial-of-service tests, or test against production data you do not own.

## Scope

Apps and sites listed on <https://rascend.com>.
